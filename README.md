# STATS 401 Individual Project

Beyond the Busiest: Comparing Railway Station Usage and Growth.

D3 redesign of ORR regional station-usage boards, comparing 15 East of England stations in 2023–24 and 2024–25.

Source: `src/`; deployable page: `site/`; report: [report.md](report.md).

Run `npm ci`, `npm run check`, and `npm run build`. Preview with `python3 -m http.server --directory site`. GitHub Actions publishes only `site/`.

ORR data and original figures are attributed on the page under the Open Government Licence v3.0.
